# Scottsdale Medical Stays — Next.js + React

A mobile-first, SEO-friendly website concept for Scottsdale Medical Stays.

## Included

- Next.js App Router
- React components
- Separate `Header.jsx` and `Footer.jsx`
- Responsive mobile-first CSS
- SEO metadata
- Open Graph metadata
- `robots.js`
- `sitemap.js`
- Attached Scottsdale Medical Stays logo
- Temporary Unsplash imagery
- Custom cactus mascot created with CSS
- Sections for properties, medical stays, comfort, care locations, reviews, process, FAQ and inquiry

## Run locally

```bash
npm install
npm run dev
```

Open:

```text
http://localhost:3000
```

## Production

```bash
npm run build
npm start
```

## Before launch

1. Replace temporary Unsplash URLs with licensed/property photography.
2. Connect the inquiry form to a secure form/email service.
3. Replace the placeholder domain in `app/layout.jsx`, `app/robots.js`, and `app/sitemap.js` if needed.
4. Add real booking URLs for The Loft, The Dutton and The Signature.
5. Add real business contact details and legal pages.
